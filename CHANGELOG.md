# Changelog

All notable changes to PSAICloudflareClef are documented here.

## [0.1.0] - 2026-10-01

### Added

- Standalone PowerShell module for Cloudflare Workers AI Clef decisions.
- `Invoke-CloudflareClefDecision` for named `noul`, `choice`, and `score` questions, with Clef Flash and embedded image support.
- `New-CloudflareClefQuestion` helper for constructing typed questions.
- Request validation, configurable timeouts, and useful HTTP error details.
- Offline Pester tests, Quick Start, and adapted Jev workflow examples, including Excel examples and sample workbooks.
- Local installation and PowerShell Gallery publishing scripts.
- README image, usage instructions, model and image limits, and Cloudflare token guidance.
